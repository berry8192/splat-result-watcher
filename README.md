# splat-result-watcher

スプラトゥーン3 の配信映像からリザルト画面を読み取り、X マッチ／バンカラマッチの勝敗・X パワー・ウデマエポイントを
表示する Windows 用のアプリです。表示ウィンドウを配信ソフトのウィンドウキャプチャで配信画面に載せられます。
読み取った結果は WebSocket（`ws://127.0.0.1:3140/events`）でも受け取れます。

> **非公式のツールです。** 任天堂株式会社とは関係ありません。「スプラトゥーン」は任天堂の商標です。

## 試合中は何も出しません

対戦相手がいるゲームで使うツールなので、**バトルに有利になる情報は出しません**。

- 試合中に出すのは「試合中である」ことと、試合が始まったこと（ルール）だけです
- 勝敗やパワーは、リザルト画面が出てから表示します
- 相手の名前・ブキ・パワーは読み取らず、保存もしません
- 入力は配信ソフトの映像だけです。Nintendo Switch Online のアプリ・API や Switch 本体には一切アクセスしません
- ゲームの音声は使いません。読み取りに生成 AI は使わず、画像の照合だけで行います

## 動作環境

- Windows 10 / 11（64bit）
- 配信ソフトのどちらか
  - **N Air**（動作確認済み）
  - **OBS Studio 28 以降**（試験的な対応です。obs-websocket を使います）
- 配信の画面は 16:9 にしてください。スプラトゥーン3 のゲーム画面も 16:9 のまま配置してください

## 使い方

### 1. ダウンロードと起動

1. [Releases](../../releases) から最新の zip をダウンロードし、好きな場所に展開します
2. `splat-result-watcher-gui.exe` を起動します
   - 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押してください
     （コード署名をしていないため表示されます）
3. 表示ウィンドウ（文字だけの小さなウィンドウ）が開きます。右クリックで設定の画面を開けます

インストールは不要です。設定などは `%LOCALAPPDATA%\splat-result-watcher` に保存されます。

### 2. キャプチャの設定

設定の画面の「設定」→「キャプチャ」で次を確認してください。変更は再起動後に反映されます。

- **キャプチャ元**: 「自動」なら N Air が起動していれば N Air を、なければ OBS を使います
  - N Air: 追加の設定は不要です。起動中の N Air から出力の映像を受け取ります
  - OBS: OBS の「ツール → WebSocket サーバー設定」で WebSocket サーバーを有効にし、ポートとパスワードを入力してください
- **ゲーム画面の位置**: 配信の画面のどこにゲーム画面があるかを指定します
  - ゲーム画面だけを配信しているなら「全画面」のままで構いません
  - ゲーム画面を縮小して配置している場合は「数値で指定」にして、配信の画面を 1920×1080 としたときの位置と大きさを入力します
  - 「状態」のページのプレビューに切り出したゲーム画面が表示されるので、ずれていないか確認してください

### 3. テンプレート

最初は内蔵の数字と、形・色の判定で読み取ります。確実に読めたものは自動でテンプレートとして追加され、だんだん読み取りが安定します。

「テンプレートの状況」のページで足りないものを確認できます。読み取れないものがあるときは、「テンプレートの登録」のページで
直近のフレーム（最大 30 分）から該当する画面を選んで登録してください。
テンプレートはご自身の画面から作る仕組みで、ゲーム画面の画像はこのアプリに含めていません。

### 4. 配信に載せる

配信ソフトに「ウィンドウキャプチャ」を追加し、`splat-result-watcher` のウィンドウを選んでください。
表示ウィンドウは左ドラッグで移動でき、右クリックで横長・縦長・背景色（透明も可）を切り替えられます。
文字の大きさや色は、設定の画面の「表示ウィンドウ」で変えられます。

## WebSocket で受け取る

`ws://127.0.0.1:3140/events` に接続すると、試合の開始・勝敗・パワーの変化などが JSON で届きます。
受信側の作り方は [docs/api.md](docs/api.md) を参照してください。

## 保存するファイルと削除

| 場所 | 中身 |
| --- | --- |
| `%LOCALAPPDATA%\splat-result-watcher\settings.json` | 設定 |
| `%LOCALAPPDATA%\splat-result-watcher\templates` など | 登録したテンプレート・送ったイベントの控え |
| `%LOCALAPPDATA%\splat-result-watcher\logs` | 動作ログ |
| `%LOCALAPPDATA%\splat-result-watcher\hits` | 検出ログ（設定で無効にできます。上限 500MB） |
| `%LOCALAPPDATA%\splat-result-watcher\samples` | 録画（設定で有効にしたときだけ） |

アンインストールするときは、展開したフォルダと `%LOCALAPPDATA%\splat-result-watcher` を削除してください。

## ソースからビルドする

Rust と Node.js が必要です。

```
npm --prefix ui install
npm --prefix ui run build
cargo build --release
```

`target\release\splat-result-watcher-gui.exe` ができます。配布用の zip は `tools\package.ps1` で作れます。
